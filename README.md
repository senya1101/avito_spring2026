## Проект: Личный кабинет продавца с интегрированным AI-ассистентом

Это тестовое задание, представляющее собой интерфейс для управления объявлениями с интеграцией AI-инструментов.

### Что было сделано

- **Главная страница**: Список всех объявлений с фильтрацией по категориям и поиском. Можно переключать вид (сетка / список).
- **Редактирование**: Полноценная форма редактирования с динамическими полями (подстраиваются под категорию товара: Авто, Недвижимость, Электроника).
- **AI-ассистент**:
  - Генерация продающего описания на основе данных товара.
  - Оценка рыночной стоимости.
- **Валидация**: Справа от формы выведен виджет, который в реальном времени показывает, какие поля не заполнены. Статус "Нужна доработка" пересчитывается автоматически при потере фокуса (onBlur) с полей.
- **404**: Обработка несуществующих роутов.

### Изменения на бэкенде

Тут внесла пару важных правок:

1.  **ID в общем списке**: Поправила ответ эндпоинта, который отдает все объявления (`/ads`). Теперь у каждого объекта в массиве сразу идет `id`. Без этого нельзя было нормально настроить переходы на страницы редактирования и идентификацию в списках.
2.  **CORS**: Переделала настройку CORS. Вместо ручных заголовков добавила официальный плагин `@fastify/cors`. Ушли проблемы с предзапросами (OPTIONS) от браузера.

### Технологии

- **Frontend**: React, TypeScript, Vite.
- **UI**: Ant Design.
- **State Management**: Redux Toolkit + RTK Query (для работы с API и кеширования).
- **Forms**: React Hook Form.

### Бэклог

ИИ-интеграция сделана через универсальную обертку. Если нужно будет добавить генерацию для динамического поля, достаточно просто в FIELD_METADATA дописать hasAiIntegration: true. И дописать DynamicField
